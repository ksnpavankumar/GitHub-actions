# GitHub-actions

Learning the basics of GitHub Actions with a simple workflow.

## Included workflow

This repository includes `.github/workflows/learn-github-actions.yml` that:
- runs on `push` and `pull_request`
- checks out the repository
- prints a learning message and basic context

## How to try it

1. Push a commit to this repository (or open a pull request).
2. Open the **Actions** tab in GitHub.
3. View the **Learn GitHub Actions** workflow run and its logs.
